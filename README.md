One funny, true line reviewing the dullest everyday object — the AA battery
in the junk drawer — written to `/output/entry.txt` by `main.py`.

> The AA battery in the junk drawer: dead since 2021, kept 'just in case', and it will outlive us all.

Built for the [make.fun bounty "The Most Boring Object, Reviewed in One Line"](https://make.fun/bounty/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3).

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The entry is a single line of 100 characters, inside the 1–200 character gate.
